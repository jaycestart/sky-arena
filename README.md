# ✈ SKY ARENA — 3D 전투기 시뮬레이터

실시간 멀티플레이어 3D 공중전. **의존성 0개** — Python 표준 라이브러리만으로
HTTP + WebSocket 서버가 돌고, 클라이언트는 빌드 없는 ES 모듈 + **WebGL 직접 렌더링**이다.
(2D 아케이드 버전은 `legacy-2d/` 에 보존)

## 실행

바탕화면의 **SKY ARENA** 바로가기를 더블클릭하거나:

```bat
play.bat
```

- 내 PC: <http://localhost:8080> · 같은 와이파이: 콘솔에 찍히는 `http://<내부IP>:8080`
- 방 나누기: `?room=이름` · 서버 상태: `/stats.json`
- 앱 설치: 홈 화면의 **홈 화면에 추가** 버튼 (PWA)

## 조종

**보조 조종이 기본으로 켜져 있다.** 커서 위치가 곧 목표 뱅크각/상승각이라,
커서를 화면 중앙에 두면 기체가 스스로 수평으로 돌아온다. 계속 도는 일이 없다.
설정에서 끄면 포인터 락 기반의 상대식 조종간(실제 시뮬 감각)으로 바뀐다.

| 입력 | 동작 |
|---|---|
| 마우스 | 조종간 — 좌우 뱅크 / 상하 상승·강하 |
| 좌클릭 / `Space` | 20mm 기총 (짧게 눌러도 발사된다) |
| 우클릭 / `F` | IR 미사일 |
| `C` | 플레어 |
| `W` `S` / 휠 | 스로틀 · `Tab` 애프터버너 · `X` 에어브레이크 |
| `A` `D` 러더 · `Q` `E` 롤 | 보조 조종을 꺼도 쓸 수 있는 직접 조종 |
| `1` `2` | 무장 전환 · `V` 콕핏/외부 시점 |

## 비행 모델 (실측 검증됨)

단순화했지만 실제 공력에 기반한다.

- **받음각 기반 양력** — 실속각을 넘으면 양력이 무너지고 조종 권한이 35%로 떨어진다.
  실속은 약 70m/s 이하에서만 일어나고, 전투 속도대에서는 G 한계가 먼저 걸린다(실제 FBW 거동).
- **항력 폴라** — 형상항력 + 유도항력 `k·CL²(1+0.75CL²)` + 천음속 항력 상승(M0.85~).
  고G 선회를 끌면 에너지가 빠지며 코너 속도로 수렴한다.
- **G 제한** — 피치 선회율이 구조 한계로 제한된다(`ω = n·g / V`). 측정값 최대 8.2G.
- **고도 효과** — 공기밀도가 지수적으로 감소해 추력·양력·조종 권한이 함께 떨어진다.
  선회 1회 소요: 저고도 6.3초 → 12km 23.4초.
- **정적 안정성** — 조종간을 놓으면 기수가 속도 벡터로 돌아온다.

기체별 실측 지속 선회율: F-16형 12.7°/s · F-15형 15.8°/s · Su-27형 16.5°/s.

## 무장

- **20mm 기총** — 탄도가 중력으로 낙차하고(1초에 약 5m) 공기저항으로 감속한다.
  HUD 조준점이 락온 거리 기준으로 낙차를 보정해 준다. 510발.
- **IR 미사일** — 후방 반구에서 잘 물린다. 락온 0.9초, 비례항법(N=4) 유도, 최대 28G.
  시커 시야를 벗어나거나 **플레어**에 속으면 놓친다. 4발.
- **플레어** — 20발. 미사일 경고(RWR)가 뜨면 뿌리면서 빔 기동.

## HUD

수평선 · 방위 테이프 · 속도(마하) / 고도(대지고도) 테이프 · 비행경로 지시자 ·
기총 조준점 · 목표 박스와 거리 · **레이더 스코프(14km)** · 화면 밖 적 방향 화살표 ·
G / 받음각 / 스로틀 · STALL·PULL UP·MISSILE 경고.

## 구조

```
server/
  app.py         HTTP(정적/ETag/stats.json) + WebSocket + 방(Room) 관리
  game.py        권위 시뮬레이션: 비행역학, 무장, 봇 AI, 스냅샷
  flightmath.py  벡터/쿼터니언/지형/대기 모델 (클라이언트 m3d.js 와 동일 공식)
  ws.py          RFC 6455 WebSocket 최소 구현
public/js/
  m3d.js     3D 수학 + 지형/대기 (서버와 동일)
  scene.js   WebGL 렌더러 — 하늘/지형/기체/예광탄/미사일 연기/플레어
  hud.js     전투기 HUD 오버레이
  world.js   예측 + 입력 재시뮬레이션 + 보간(위치 lerp, 자세 slerp)
  input.js   보조 조종 / 직접 조종
  audio.js   WebAudio 합성 효과음(엔진·기총·폭발·경고)
  net.js, main.js
```

## 네트워크

- **서버 권위** 50Hz 시뮬레이션 / **25Hz 델타 스냅샷**.
- 클라이언트는 좌표가 아니라 조종 입력만 30Hz로 보낸다.
- **시야 컬링** 14km — 밖의 기체는 레이더 접촉으로만 전송.
- **델타 압축** — 자세·위치는 매번, 체력·상태는 바뀔 때만.
- **입력 재시뮬레이션** — 스냅샷이 오면 서버 상태로 되감고 미확인 입력을 재적용.
- 기총은 초당 50발을 서버에서 모두 판정하되 **예광탄만 3발에 1발씩** 전송한다.

## 격추

지면 충돌 또는 체력 0 → 잔해가 회전하며 낙하한다(2초에 169m, 낙하속도 112m/s).
2.6초 뒤 재출격.
